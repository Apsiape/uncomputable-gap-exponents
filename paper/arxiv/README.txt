Uncomputable critical exponents
Seth Douglas and Nidhal Mghirbi
Version 2.0.0, October 2026. A preprint; it has not been peer reviewed.

This directory builds independently.
Run python build.py --output-dir BUILD_DIRECTORY outside this source folder,
or run pdflatex main.tex, bibtex main, and pdflatex main.tex twice.
All section sources, bibliography, recorded finite checks and SHA-256 hashes
are included. NumPy, SciPy and psutil are needed only to rerun anc/run_checks.py.
